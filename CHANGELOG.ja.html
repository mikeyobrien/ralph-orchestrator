    変更履歴

    ralph-orchestrator への注目すべき変更はすべてここに記録されます。

    形式は Keep a Changelog に基づいており、この プロジェクトは セマンティックバージョニング に 従います。

    2.10.1 - 2026-06-22

    修正

    • カセットベースのカスタムバックエンドに標準入力経由でプロンプトを渡すことで、e2e の モックモード検証を復旧しました。
    • モック e2e の単一イテレーションシナリオを、旧来のスクラッチパッド書き込みではなく完了 シグナルを検証するよう更新しました。
    • gitignore の統合テストを、ユーザー/グローバルの Git 除外ファイルから分離しました。

    2.10.0 - 2026-06-21

    追加

    • Forge CLI バックエンドの統合。
    • コントロールプレーンにおける RObot（ヒューマンインザループ）RPC ドメイン。加えて、 ライブソケットではなくファイルを通じて人間との対話を駆動するファイルベースの Web モード。
    • ワークツリーループがリモートのレビューブランチを公開できるようになり、リベースにも対応。
    • 事前確認におけるローカルのファイルベースのハットインポート。インポートの解決と、 インポート元ファイルのコンテキストを伴うスキーマ検証を含む。
    • TUI のイテレーションバッファをディスクへオンデマンドでエクスポート: e は現在の イテレーションを、E はすべてのイテレーションをエクスポート。
    • TUI に表示される、コンテキストウィンドウ使用率のテレメトリ。

    変更

    • Pi バックエンドのパッケージ参照を @earendil-works/pi-coding-agent に更新しました。
    • エージェント波の可観測性ドキュメントを刷新し、ハットインポートの設計スペックを追加 しました。

    修正

    • TUI の検索モードは、入力されたクエリ文字をキーバインドに漏らすのではなく取り込むように なりました（例: クエリ中の e がエクスポートを起動しなくなった）。Search: プロンプト、 N/M の一致カウンタ、n/N のナビゲーションが再び機能します。
    • ランタイムはガイダンスの後に明示的な完了シグナルを要求するようになり、ループの早期終了を 防止します。
    • ループの継続状態をイテレーションをまたいで永続化します。
    • 生成される指示において、ハットごとのスクラッチパッド設定を尊重します。
    • 終了前に ACP ターミナル出力を排出し、最終出力が切り詰められないようにします。
    • パスの不一致エラーを避けるため、Ralph の成果物パスを正規化します。
    • API 上で公開される MCP ツールスキーマの重複を排除します。

    2.9.3 - 2026-05-08

    追加

    • llms.txt 駆動の内省のための ralph-docs スキル。
    • -H <name> 配下の統一プリセット機構。YAML と TOML の両プリセットに対応。
    • kiro-acp バックエンド向けの ralph plan 対応。完了時のフォールバックを含む。
    • ライブなエージェント観察を伴うビジュアルワークフローエディタ（ビルダー）。
    • ハットごとのスクラッチパッド設定。
    • ハットがキャンセルの約束（cancellation promise）を設定できるように。
    • ループバナー、イテレーションごとのフッター、再開ヒントを備えた --no-tui の UX 改善。

    変更

    • Amazon Linux 2 / 2023 との互換性のため、Linux の配布ターゲットを musl に切り替えました。
    • フック用のグローバルなユーザー設定を文書化し、FAQ セクションを追加し、TOML プリセット 形式の autoloop 作成ガイドをリンクしました。

    修正

    • Claude の子セッションは既定で --setting-sources project,local を使うようになり、 ホストのユーザーレベルの ~/.claude/settings.json のフック、プラグイン、MCP サーバーが Ralph のオーケストレーション実行に漏れ込むのを防ぎます。旧来の挙動を望むユーザーは cli.args: ["--setting-sources", "user,project,local"] で元に戻せます。
    • テキスト完了のフォールバックを check_completion_event() を通すようにしました。
    • RALPH_EVENTS_FILE 環境変数を伝播し、遅延した終了理由を保持します。
    • 残存するテキストバックエンドがループの進行を停滞させるのを防ぎます。
    • Rust 1.95 の duration_suboptimal_units clippy 警告を解消します。

    セキュリティ

    • sync-embedded-files.sh において source を安全な変数パーサに置き換えました。
    • test-fresh-install.sh で npm install ではなく npm ci を使用します。

    2.9.2 - 2026-04-10

    変更

    • Pi と Roo バックエンド向けに ralph doctor の認証環境変数の検出を拡張しました。
    • バックエンドガイドで Pi バックエンドを文書化しました。

    修正

    • 非対話的な PTY 実行における PTY 標準入力のデッドロックを回避し、大きなプロンプトでの Claude + TUI の空白/停止出力を修正しました。

    2.8.0 - 2026-03-10

    追加

    • ユーザースコープの既定設定の探索と、ユーザーごとの Ralph 既定値のサポート。
    • TUI ヘッダーでの更新可否の通知。
    • 人間のガイダンスがクリーンな再起動要求フローを起動できるように。

    変更

    • コアのプリセット群を、維持されているワークフローに集約し、プリセットのドキュメント、例、 評価ツールを刷新しました。
    • Ralph 固有のノイズを減らし引き継ぎの品質を高めるため、PDD とコードタスクのガイダンスを 洗練しました。

    修正

    • ハット使用時に、コア設定のランタイム上限を保持するようにしました。
    • ヘッドレスループランナーのバックエンド選択を修正しました。
    • 再起動の再開が必須の単一コマンドシェルフローを使うようにし、その契約カバレッジを追加 しました。

    2.7.0 - 2026-03-06

    追加

    • プロジェクトごとのオーケストレーターのライフサイクルフック v1。
    • ACP エグゼキュータ対応の kiro-acp バックエンド。
    • JSON-RPC の標準入出力上のサブプロセス TUI。
    • ACP ベースのフロー向けの TUI ツール描画の改善。

    変更

    • 冗長なクローンを削除し now_ts の重複を排除して、内部のコード経路を簡素化しました。
    • 非推奨の Duration メソッドの使用を from_secs に置き換えました。
    • ralph plan の PDD SOP は、正規の strands-agents/agent-sop 上流ソースから同期する ようになり、小さな Ralph 固有のループ引き継ぎの追補を伴います。
    • SOP 保守のための、埋め込みアセットの同期・チェック・上流リフレッシュのヘルパを追加 しました。
    • プリセットのドキュメントを統一し近代化しました。
    • llms.txt マップの生成と CI 検証を追加しました。
    • Web の tsx 事前確認の挙動を堅牢化し、資金提供のメタデータを追加しました。

    修正

    • サブプロセス TUI モードでの自己ロックの競合を回避します。
    • TUI において Pi のテキストデルタを流れる段落に蓄積します。
    • ゾンビ化したワークツリーループをより確実に片付けます。
    • ACP の孤立プロセス、乱れた TUI 出力、欠落したツール詳細を修正します。
    • clippy の問題と欠落した構造体フィールドを解消します。
