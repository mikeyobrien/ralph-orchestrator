    貢献者行動規範（Contributor Covenant Code of Conduct）

    私たちの誓い

    私たちメンバー、コントリビューター、およびリーダーは、年齢、体格、目に見える・見えない 障害、民族性、性的特徴、性自認と性表現、経験の水準、教育、社会経済的地位、国籍、容姿、 人種、カースト、肌の色、宗教、性的指向に関わらず、コミュニティへの参加をすべての人にとって ハラスメントのない体験にすることを誓います。

    私たちは、開かれた、歓迎的で、多様性に富み、包摂的で、健全なコミュニティに寄与するように 行動し、交流することを誓います。

    私たちの基準

    コミュニティにとって前向きな環境に寄与する行動の例:

    • 他者への共感と親切さを示すこと
    • 異なる意見、視点、経験を尊重すること
    • 建設的なフィードバックを与え、また快く受け入れること
    • 自分の過ちの影響を受けた人々に責任を認めて謝罪し、その経験から学ぶこと
    • 個人としての自分だけでなく、コミュニティ全体にとって最善なことに焦点を当てること

    容認できない行動の例:

    • 性的な言葉や表現の使用、およびあらゆる種類の性的な関心や誘い
    • 荒らし行為、侮辱的または中傷的なコメント、個人的または政治的な攻撃
    • 公的または私的なハラスメント
    • 明示的な許可なく、物理的な住所やメールアドレスなど他者の私的情報を公開すること
    • 職業上の場において不適切と合理的に見なされ得るその他の行為

    執行の責任

    コミュニティのリーダーは、容認される行動の基準を明確にし執行する責任を負い、不適切、脅迫的、 攻撃的、または有害と見なす行動に対して、適切かつ公正な是正措置を講じます。

    コミュニティのリーダーは、この行動規範に沿わないコメント、コミット、コード、Wiki の編集、 issue、その他の貢献を削除、編集、または拒否する権利と責任を持ち、適切な場合にはモデレー ションの判断理由を伝えます。

    適用範囲

    この行動規範は、すべてのコミュニティ空間内で適用され、また個人が公の場でコミュニティを公式に 代表している場合にも適用されます。コミュニティを代表する例には、公式なメールアドレスの使用、 公式なソーシャルメディアアカウントでの投稿、オンラインまたはオフラインのイベントでの任命された 代表としての行動などが含まれます。

    執行

    虐待的、ハラスメント的、またはその他の容認できない行動の事例は、 issue を開く ことで、 執行を担当するコミュニティのリーダーに報告できます。すべての苦情は迅速かつ公正に確認・調査 されます。

    すべてのコミュニティのリーダーは、いかなる事案の報告者についても、そのプライバシーと安全を 尊重する義務を負います。

    執行ガイドライン

    コミュニティのリーダーは、この行動規範に違反すると見なす行為の結果を判断する際、次の コミュニティ影響ガイドラインに従います。

    1. 是正

    コミュニティへの影響: 不適切な言葉遣い、またはコミュニティにおいて非専門的・歓迎され ないと見なされるその他の行動。

    結果: コミュニティのリーダーからの私的で書面による警告。違反の性質を明確にし、なぜその 行動が不適切であったかを説明します。公的な謝罪が求められる場合があります。

    2. 警告

    コミュニティへの影響: 単一の事案または一連の行為による違反。

    結果: 継続した場合の結果を伴う警告。一定期間、関係者との交流を禁じます。これには行動規範 を執行する者への一方的な接触も含まれます。コミュニティ空間内はもちろん、ソーシャルメディア などの外部チャネルでの交流を避けることも含まれます。これらの条件に違反すると、一時的または 恒久的な追放につながる場合があります。

    3. 一時的な追放

    コミュニティへの影響: 継続的な不適切行動を含む、コミュニティ基準への重大な違反。

    結果: 一定期間、コミュニティとのあらゆる種類の交流または公的なコミュニケーションからの 一時的な追放。この期間中、行動規範を執行する者への一方的な接触を含め、関係者との公的または 私的な交流は一切許可されません。これらの条件に違反すると、恒久的な追放につながる場合が あります。

    4. 恒久的な追放

    コミュニティへの影響: 継続的な不適切行動、個人へのハラスメント、または特定の集団への 攻撃や中傷を含む、コミュニティ基準への違反のパターンを示すこと。

    結果: コミュニティ内でのあらゆる種類の公的な交流からの恒久的な追放。
