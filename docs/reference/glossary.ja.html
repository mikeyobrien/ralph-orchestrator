Ralph Orchestrator 日本語ドキュメント
目次

    用語集

    A

    Agent（エージェント） : プロンプトに基づいてタスクを実行する AI 搭載の CLI ツール。Ralph は Claude、Gemini、 Q エージェントをサポートする。

    Agent Manager（エージェントマネージャ） : AI エージェントを検出、選択、管理するコンポーネント。優先エージェントが利用できないときの 自動フォールバックを含む。

    Archive（アーカイブ） : デバッグと分析のために、過去のプロンプトとイテレーションを .agent/prompts/ ディレクトリに保存すること。

    Auto-detection（自動検出） : どの AI エージェントがシステムにインストールされ利用可能かを自動的に発見する Ralph の 能力。

    C

    Checkpoint（チェックポイント） : 進捗を保存し回復を可能にするため、一定間隔で作成される Git コミット。既定の間隔は 5 イテレーションごと。

    Claude : Claude Code CLI を通じてアクセスできる Anthropic の AI アシスタント。高いコンテキスト ウィンドウ（20 万トークン）とコード生成能力で知られる。

    CLI : Command Line Interface（コマンドラインインターフェース）- ターミナルコマンドを通じて Ralph Orchestrator と対話する主要な方法。

    Config（設定） : ralph.json に保存されるか、コマンドライン引数と環境変数で渡される設定。

    Context Window（コンテキストウィンドウ） : AI エージェントが単一のリクエストで処理できる最大のテキスト/トークン量。エージェントに より異なる（Claude: 200K、Gemini: 32K、Q: 8K）。

    Convergence（収束） : 連続した改善を通じて、イテレーションが徐々にタスク完了に近づくプロセス。

    Completion Marker（完了マーカー） : タスク完了を知らせる、プロンプトファイル内の特別なチェックボックスパターン （- [x] TASK_COMPLETE）。オーケストレーターはこのマーカーを検出すると、直ちにループを 終了する。

    D

    Dry Run（ドライラン） : 実際に AI エージェントを実行せずに実行をシミュレートするテストモード。設定とセットアップの テストに便利。

    Deterministic Failure（決定的な失敗） : 予測不能に成功するより予測可能に失敗するほうがよいという哲学。Ralph Wiggum テクニックの 中核。

    E

    Exponential Backoff（指数バックオフ） : 一時的なエラーを扱うため、各失敗の後に待ち時間が倍になる（2, 4, 8, 16 秒）リトライ戦略。

    Execution Cycle（実行サイクル） : プロンプトを読み、エージェントを実行し、完了を確認し、状態を更新する 1 つの完全な イテレーション。

    G

    Gemini : Gemini CLI を通じてアクセスできる Google の AI モデル。バランスの取れたコンテキスト ウィンドウ（32K トークン）と能力。

    Git Integration（Git 統合） : チェックポイント、履歴追跡、失敗状態からの回復のための Ralph の Git 利用。

    I

    Iteration（イテレーション） : Ralph ループの 1 つの完全なサイクル - 現在のプロンプトでエージェントを実行し、結果を 処理する。

    Iteration Limit（イテレーション上限） : Ralph が停止するまでの最大イテレーション数。既定は 100、max_iterations で設定可能。

    L

    Loop（ループ） : Ralph の中核パターン - タスク完了または上限到達まで AI エージェントを継続的に実行する。

    Loop Detection（ループ検出） : エージェントが反復的な出力を生成しているときを検出する安全機能。ファジー文字列マッチ （rapidfuzz）を 90% の類似度しきい値で使い、最近の出力を比較して無限ループを防ぐ。

    M

    Metrics（メトリクス） : タイミング、エラー、リソース使用を含む、.agent/metrics/ に収集されるパフォーマンスと 実行のデータ。

    MkDocs : Ralph のドキュメントに使われる静的サイトジェネレータ。mkdocs.yml で設定される。

    O

    Orchestrator（オーケストレーター） : 実行ループ、エージェントとの対話、状態管理を扱う主要なコンポーネント。

    P

    Prompt（プロンプト） : AI エージェントに何を達成すべきかを伝えるタスク記述ファイル（通常 PROMPT.md）。

    Prompt Archive（プロンプトアーカイブ） : デバッグと分析のための、すべてのプロンプトイテレーションの .agent/prompts/ への 履歴保存。

    Plugin（プラグイン） : カスタムのエージェントやコマンドを Ralph に追加するための拡張の仕組み。

    Q

    Q Chat : Q CLI を通じてアクセスできる AI アシスタント。小さいコンテキストウィンドウ（8K トークン）だが高速な実行。

    R

    Ralph Wiggum Technique（Ralph Wiggum テクニック） : タスクが完了するまで AI エージェントをループに入れるソフトウェアエンジニアリングの パターン。Geoffrey Huntley が考案。

    Recovery（回復） : 失敗や中断の後に、保存された状態や Git チェックポイントから実行を再開するプロセス。

    Retry Logic（リトライロジック） : 一時的な失敗を扱うための、指数バックオフを伴う自動リトライの仕組み。

    Runtime Limit（実行時間上限） : Ralph が停止するまでの最大実行時間（秒）。既定は 14400（4 時間）。

    S

    State（状態） : イテレーション数、エラー、メトリクスを含む現在の実行状況。 .agent/metrics/state_latest.json に保存される。

    State Manager（状態マネージャ） : イテレーションをまたいで実行状態を保存、読み込み、更新する責任を持つコンポーネント。

    Success Criteria（成功基準） : オーケストレーターを完了へと導く、PROMPT.md で定義される測定可能な目標。

    T

    Task（タスク） : 達成すべき作業。要件と成功基準とともに PROMPT.md に記述される。

    Task Complete（タスク完了） : オーケストレーターが、定義された目標に向けて作業した上で、最大イテレーション、実行時間、 またはコスト上限に達した状態。

    Timeout（タイムアウト） : 単一のエージェント実行に許される最大時間。既定はイテレーションあたり 300 秒（5 分）。

    Token（トークン） : AI モデルが処理するテキストの単位。おおよそ 4 文字 = 1 トークン。

    U

    Unpossible : Ralph Wiggum の台詞への言及。粘り強さを通じて一見不可能なことを達成する哲学を体現する。

    V

    Verbose Mode（詳細モード） : デバッグと監視のために --verbose フラグで有効にする詳細ログモード。

    W

    Working Directory（作業ディレクトリ） : Ralph が実行されるディレクトリ。PROMPT.md とプロジェクトファイルを含む。既定は現在の ディレクトリ。

    Workspace（ワークスペース） : メトリクス、チェックポイント、アーカイブを含む Ralph の運用データを格納する .agent/ ディレクトリ。

    技術用語

    API : Application Programming Interface - Ralph が AI サービスと通信するインターフェース。

    JSON : JavaScript Object Notation - 設定ファイルと状態保存に使われる形式。

    Subprocess（サブプロセス） : AI エージェントを実行するために生成される別プロセス。分離とタイムアウト制御を提供する。

    YAML : YAML Ain't Markup Language - 一部の設定ファイルに使われる人間が読みやすいデータ形式。

    ファイル形式

    .md : プロンプトとドキュメントに使われる Markdown ファイル。

    .json : 設定と状態保存に使われる JSON ファイル。

    .yaml/.yml : 設定に使われる YAML ファイル（例: mkdocs.yml）。

    .log : 実行履歴とデバッグ情報を含むログファイル。

    ディレクトリ構成

    .agent/ : すべての運用データを含む Ralph のワークスペースディレクトリ。

    .agent/metrics/ : 実行メトリクスと状態ファイルの保存場所。

    .agent/prompts/ : 過去のプロンプトイテレーションのアーカイブ。

    .agent/checkpoints/ : 実行中に作成された Git チェックポイントのマーカー。

    .agent/logs/ : デバッグと分析のための実行ログ。

    .agent/plans/ : エージェントの計画ドキュメントと長期戦略。

    コマンドリファレンス

    ralph run : 現在の設定でオーケストレーターを実行する。

    ralph init : 既定の構成で新しい Ralph プロジェクトを初期化する。

    ralph status : 現在の実行状況とメトリクスを確認する。

    ralph clean : ワークスペースをクリーンにし状態をリセットする。

    ralph agents : システム上の利用可能な AI エージェントを一覧する。

    環境変数

    RALPH_AGENT : 既定のエージェント選択を上書きする。

    RALPH_MAX_ITERATIONS : 最大イテレーション上限を設定する。

    RALPH_MAX_RUNTIME : 最大実行時間（秒）を設定する。

    RALPH_VERBOSE : 詳細ログを有効にする（true/false）。

    RALPH_DRY_RUN : ドライランモードを有効にする（true/false）。

    終了コード

    0: 成功 - タスクが正常に完了した

    1: 一般的な失敗 - 詳細はログを確認する

    130: 割り込み - ユーザーが Ctrl+C を押した

    137: 強制終了 - プロセスが終了した（多くはメモリの問題）

    124: タイムアウト - 実行時間を超過した
