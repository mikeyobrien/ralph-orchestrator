# Ralph Wiggum テクニック

Ralph Wiggum テクニックは、継続的な反復による自律的な AI タスク完了への、単純でありながら
強力なアプローチです。

## 起源

このテクニックは [Geoffrey Huntley](https://ghuntley.com/ralph/) によって考案され、
ザ・シンプソンズの Ralph Wiggum にちなんで名付けられました。粘り強い反復の哲学を体現して
います。「僕が英語で失敗する？そんなの不可能だい！」 — 成功するまでただ挑み続けるのです。

## 基本的な考え方

その核心は、Huntley が当初定義したとおり、**「Ralph は Bash ループである」** という
ものです。

```bash
while :; do cat PROMPT.md | claude ; done
```

この単純なアプローチは「非決定的な世界において決定的にダメ」です。予測可能な形で失敗します
が、その失敗は対処できる形です。このテクニックには「結果整合性への信頼と信念」が必要で、
反復的なチューニングを通じて改善していきます。

## なぜうまくいくのか

従来の AI ワークフローは、逐次的に指示します。

```
人間: ステップ 1 をやって
AI: 完了
人間: 次にステップ 2 をやって
AI: 完了
人間: 次にステップ 3 を…
```

Ralph Wiggum テクニックは、**成功基準を最初に定義する**ことでこれを反転させます。

```
人間: これが成功の姿だ。そこに至るまで続けて。
AI: [成功するまで反復する]
```

AI は複数のイテレーションを通じて自己修正し、次の能力を活かします。

- うまくいっていないことを認識する
- 異なるアプローチを試す
- 以前の試行の上に積み上げる
- 最終的に解に収束する

## 主要な性質

### 1. 各イテレーションのフレッシュコンテキスト

各サイクルはまっさらな状態から始まります。AI はプロンプトを読み直し、コードベースを分析し
直し、新たに判断します。これにより局所最適に陥るのを防ぎます。

### 2. ディスクは状態

ディスク上のファイルが唯一の永続的な状態です。

- プロンプトファイル（`PROMPT.md`）
- コードベースそのもの
- Git 履歴
- メモリファイル（`.ralph/agent/memories.md`）

### 3. 結果整合性

このテクニックは即座の成功を保証しません。十分な回数の反復があれば、タスクが達成可能で
ある限り、解が現れることを保証します。

### 4. 予測可能な失敗モード

Ralph が失敗するとき、それは予測可能な形で失敗します。

- イテレーション上限に到達
- 費用の上限を超過
- 時間の上限を超過
- ループ検出（反復的な出力）

これらはすべて観測可能で、対処可能です。

## 実世界の成果

このテクニックはスケールでの有効性が実証されています。

- **Y Combinator ハッカソン**: チームが Ralph ループを使って一晩で 6 つのリポジトリを
  出荷
- **契約 MVP**: 1 人のエンジニアが、わずか 297 ドルの API 費用で 5 万ドルの契約を完了
- **言語開発**: Geoffrey Huntley の 3 か月のループが、完全な難解プログラミング言語
  （CURSED）を生み出した

## 使う場面

Ralph が得意なこと:

- 大規模なリファクタリングと移行
- バッチ操作（ドキュメント、テスト）
- グリーンフィールドプロジェクトの足場作り
- 明確な完了基準を持つ、よく定義されたタスク

Ralph が苦手なこと:

- 曖昧な要件
- 人間の判断を要するタスク
- セキュリティに敏感なコード
- 探索的な作業

## 強化された実装

Ralph Orchestrator は、基本的なテクニックを次のように拡張します。

| 機能 | 用途 |
|---------|---------|
| **マルチバックエンド対応** | Claude、Kiro、Gemini などで動作 |
| **ハットシステム** | 複雑なワークフローのための専門ペルソナ |
| **バックプレッシャー** | 不完全な作業を拒否する品質ゲート |
| **TUI** | 進捗のリアルタイム監視 |
| **メモリ** | セッションをまたいだ永続的な学習 |
| **安全上限** | イテレーション、費用、時間の上限 |

## 哲学

> 「Ralph に Ralph させる」 — ループの*中*ではなく、ループの*上*に座る。

目標は、オーケストラを指揮するのではなく、ギターをチューニングするようにすることです。
制約とシグナルを整えたら、あとは Ralph に任せます。
