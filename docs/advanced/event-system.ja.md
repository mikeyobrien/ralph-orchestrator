## 概要

Ralph のイベントシステムは、ハットのオーケストレーションのための通信の背骨を提供します。
エージェントが、ハットの切り替えやバックプレッシャーの仕組みを起動する信号を発行できるように
します。

## イベントの種類

| イベント | 説明 |
|-------|-------------|
| `plan:complete` | 計画フェーズが完了した |
| `code:complete` | 実装フェーズが完了した |
| `test:pass` | テストが通った |
| `test:fail` | テストが失敗した |
| `LOOP_COMPLETE` | タスクが完全に完了した |

## イベントの発行

```bash
ralph emit plan:complete
ralph emit test:pass
```
