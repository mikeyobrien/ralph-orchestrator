## 概要

Ralph のメモリシステムは、`.agent/memories.md` に保存され、オーケストレーションセッションを
またいだ永続的な学習を提供します。

## メモリの種類

- **コードベースのパターン** - 発見された慣習とパターン
- **アーキテクチャの決定** - 設計の選択とその根拠
- **繰り返し使う解決策** - よくある問題解決のアプローチ
- **プロジェクトのコンテキスト** - ドメイン固有の知識

## 設定

```yaml
memories:
  enabled: true  # Default
  path: .agent/memories.md
```
