# タスク: REST API を構築する

ユーザー管理機能を備えた Flask の REST API を作成してください。

## 要件

- [ ] Flask アプリケーションの構成
- [ ] id、name、email を持つ User モデル
- [ ] CRUD エンドポイント:
  - GET /users - すべてのユーザーを一覧する
  - GET /users/<id> - 特定のユーザーを取得する
  - POST /users - 新しいユーザーを作成する
  - PUT /users/<id> - ユーザーを更新する
  - DELETE /users/<id> - ユーザーを削除する
- [ ] 入力バリデーション
- [ ] エラー処理
- [ ] ユニットテスト
- [ ] ドキュメント

## 技術仕様

- Flask 2.0 以降を使用する
- データ保存には SQLite を使用する
- JSON レスポンスを返す
- 適切な HTTP ステータスコード
- RESTful な設計原則

## 成功基準

- すべてのエンドポイントが機能する
- テストが通る
- エッジケースを処理する
- 明確なエラーメッセージ
