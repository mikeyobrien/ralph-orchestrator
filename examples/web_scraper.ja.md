# Web スクレイパーの例

次のような Python 製 Web スクレイパーを構築してください。

1. Hacker News（https://news.ycombinator.com）のトップストーリーをスクレイピングする
2. 以下を抽出する:
   - タイトル
   - URL
   - ポイント
   - コメント数
   - 投稿時刻

3. データを次の両方に保存する:
   - JSON ファイル（`hn_stories.json`）
   - CSV ファイル（`hn_stories.csv`）

4. レート制限を実装する（1 秒あたり 1 リクエスト）
5. ネットワーク障害に対するエラー処理を含める
6. デバッグ用のロギングを追加する

要件:
- requests と BeautifulSoup を使用する
- robots.txt のガイドラインに従う
- `main()` 関数を含める
- 取得するストーリー数を指定するコマンドライン引数を追加する

`hn_scraper.py` として保存してください。

オーケストレーターは、スクレイパーが完全に実装されるまでイテレーションを継続します。
